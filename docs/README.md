# Tetris Deep Q-Learning docs

## Agents: read first

- These docs follow [Diátaxis](https://diataxis.fr/). Put each page in the folder of its type.
- Files outside `docs/` must not link to `docs/`. Files in `docs/` can link to project files with relative links.
- Keep the English and Vietnamese pages of the same topic in step: change both in the same edit.

| Folder | Diátaxis type | Pages |

| `explanation/` | understanding: ideas and reasons | [Lecture (English)](explanation/lecture.en.md), [Bài giảng (Tiếng Việt)](explanation/lecture.vi.md) |
